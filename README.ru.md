Лишенные неба, погребенные под сотнями метров бетона, люди не объединились. Вместо этого они вытащили из прошлого свои самые старые пороки: радикальный капитализм, тоталитарную ностальгию, ксенофобию и искусственно развязанные войны. Они построили клетки внутри клетки.

## Анатомия систем: Деконструкция фракций

Исследование раскладывает постапокалиптическое общество на ключевые центры власти:

* **Ганза (Содружество Кольца)** — *Радикальный капитализм и торговая олигархия.*  
  Обмен человеческой души на комфорт и электричество. Предсказуемость ценой корпоративного рабства.
* **Красная Линия** — *Неокоммунизм и тоталитаризм.*  
  Ностальгия, превращенная в оружие партии. Равенство в нищете в обмен на слепое подчинение идеологии.
* **Четвертый Рейх** — *Фашизм и биологическая чистота.*  
  Абсолютный страх перед внешними мутациями, ставший машиной геноцида. Порядок ценой человечности.
* **Полис** — *Академическая меритократия и техносфера.*  
  Заповедник культуры и науки старого мира, парализованный кастовым снобизмом и бессильный без внешней армии.
* **Орден «Спарта»** — *Рыцарский парадокс.*  
  Элитный спецназ человечества; идеалисты, неосознанно ставшие инструментами в чужих кулуарных играх.
* **Невидимые Наблюдатели** — *Архитектура управляемого страха.*  
  Тотальный информационный купол: поддержание вечной войны в туннелях, чтобы никто не смел взглянуть наверх.

## Инженерия: Философия чистого веба (Anti-Noise)

Большинство современных веб-приложений создают то, что призваны уничтожить: **информационный шум, лишние абстракции и задержки.**  
Этот сайт спроектирован как манифест цифровой чистоты.

* **Zero Dependencies.** Ноль npm-пакетов. Ноль сборщиков. Ноль фреймворков. Только чистые нативные веб-стандарты.
* **Субмиллисекундный рендеринг.** Практически нулевой Time to Interactive (TTI). Страница отображается мгновенно с первым пришедшим TCP-пакетом.
* **Чистая мультиязычная архитектура.** Двусторонний кластер страниц по спецификации W3C (`hreflang` + `canonical`), признанный и проиндексированный нейросетями поиска (Яндекс Алиса AI / Google Search).
* **Тактильная типографика.** Темный визуальный холст, откалиброванный для непрерывного вдумчивого чтения без усталости глаз.

## Локальный запуск

Никаких `npm install` и установочных пайплайнов.

```bash
# Клонировать репозиторий
git clone https://github.com/Vancore/metro-universe-factions

# Перейти в каталог проекта
cd metro

# Открыть в любом браузере
open index.html   # Русская версия
open en.html      # Английская версия
```
